## 🎯 프로젝트 개요

Member Service는 **사용자 프로필**과 **회원 정보**를 관리하는 **회원 관리 서비스**입니다.

### 🌟 주요 특징

- **프로필 관리**: 닉네임, 프로필 이미지, 개인 정보 관리
- **회원 정보 캐싱**: Redis를 통한 고성능 사용자 정보 조회
- **이벤트 기반 통신**: Kafka를 통한 다른 서비스와의 연동
- **파일 업로드**: 프로필 이미지 업로드 및 관리
- **회원 통계**: 가입 현황 및 활동 통계

### 🏆 핵심 역할

- **사용자 정보 관리**: 회원 프로필 CRUD 작업
- **프로필 이미지 관리**: 이미지 업로드 및 저장
- **회원 상태 관리**: 활성/비활성 상태 관리
- **통계 제공**: 회원 가입 및 활동 통계

## 🛠️ 기술 스택

### Backend
- **Java 17** - OpenJDK LTS 버전
- **Spring Boot 3.5.0** - 최신 Spring Boot 프레임워크
- **Spring Data JPA** - ORM 및 데이터 접근 계층
- **QueryDSL** - 타입 안전한 쿼리 작성
- **Spring Web** - RESTful API 구현

### Database & Cache
- **MySQL 8.0** - 메인 데이터베이스
- **Redis 7.0** - 캐시 및 세션 저장소
- **HikariCP** - 커넥션 풀 관리

### Message Queue
- **Apache Kafka** - 이벤트 기반 통신
- **Spring Cloud Stream** - 스트림 처리

### Service Discovery & Documentation
- **Netflix Eureka Client** - 서비스 디스커버리
- **SpringDoc OpenAPI 3** - API 문서화
- **Swagger UI** - API 테스트 인터페이스

### Infrastructure
- **Docker** - 컨테이너화
- **AWS S3** - 파일 저장소
- **AWS EC2** - 클라우드 배포

## 🚀 주요 기능

### 1. 회원 프로필 조회
- **캐시 우선 조회**: Redis 캐시에서 먼저 조회
- **데이터베이스 폴백**: 캐시 미스 시 DB 조회
- **자동 캐싱**: 조회된 데이터 자동 캐시 저장

### 2. 프로필 정보 수정
- **프로필 업데이트**: 사용자 정보 수정
- **캐시 동기화**: 수정된 데이터 캐시 업데이트
- **이벤트 발행**: 다른 서비스에 변경사항 알림

### 3. 프로필 이미지 업로드
- **이미지 검증**: 파일 형식 및 크기 검증
- **S3 업로드**: AWS S3에 이미지 저장
- **URL 업데이트**: 프로필 이미지 URL 업데이트

### 4. 회원 통계 조회
- **가입 현황**: 회원 가입 통계
- **활동 분석**: 사용자 활동 패턴 분석
- **실시간 지표**: 현재 활성 사용자 수

## ⚙️ 환경 설정

### 필수 요구사항
- Java 17 이상
- MySQL 8.0 이상
- Redis 7.0 이상
- Docker (선택사항)

### 환경 변수
- **DATABASE_URL**: MySQL 데이터베이스 연결 정보
- **REDIS_URL**: Redis 서버 연결 정보
- **KAFKA_BOOTSTRAP_SERVERS**: Kafka 서버 정보
- **AWS_S3_BUCKET**: S3 버킷 이름
- **AWS_ACCESS_KEY_ID**: AWS 액세스 키
- **AWS_SECRET_ACCESS_KEY**: AWS 시크릿 키

## 🚀 실행 방법

### 1. 저장소 클론
프로젝트 저장소를 로컬에 클론합니다.

### 2. 데이터베이스 설정
MySQL 데이터베이스와 Redis 서버를 준비합니다.

### 3. 환경 변수 설정
필요한 환경 변수를 설정합니다.

### 4. 애플리케이션 실행
Gradle을 통해 애플리케이션을 실행합니다.

### 5. 접속 확인
- API 엔드포인트: http://localhost:8082
- Swagger UI: http://localhost:8082/swagger-ui/index.html

## 📚 API 문서

### Swagger UI 접속
API 문서는 Swagger UI를 통해 확인할 수 있습니다.

### 주요 API 엔드포인트

#### 프로필 관리
- **회원 프로필 조회**: 특정 회원의 프로필 정보 조회
- **프로필 정보 수정**: 회원 프로필 정보 업데이트
- **프로필 이미지 업로드**: 프로필 이미지 업로드 및 저장
- **프로필 이미지 삭제**: 프로필 이미지 삭제

#### 회원 정보
- **회원 상세 정보 조회**: 회원 상세 정보 조회
- **회원 정보 수정**: 회원 정보 업데이트
- **회원 탈퇴**: 회원 계정 삭제 처리

#### 회원 목록
- **회원 목록 조회**: 전체 회원 목록 조회 (페이징 지원)
- **회원 검색**: 이름, 이메일 등으로 회원 검색

#### 통계
- **회원 통계 조회**: 전체 회원 가입 및 활동 통계
- **일별 가입 통계**: 일별 회원 가입 현황

## 🔧 주요 설정

### 캐시 설정
Redis를 통한 회원 정보 캐싱으로 조회 성능을 향상시킵니다.

### 파일 업로드 설정
AWS S3를 통한 프로필 이미지 업로드 및 관리가 설정되어 있습니다.

### 메시지 큐 설정
Kafka를 통한 이벤트 기반 통신으로 다른 서비스와 연동됩니다.
